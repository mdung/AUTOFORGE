# AutoForge — Product Overview

## Vision
AutoForge is the operating system for automotive service, repair, maintenance, parts, and aftersales operations. It unifies fragmented workshop workflows into a single multi-tenant operational source of truth.

## Target Customers
- Independent garages
- Multi-location workshop chains
- Authorized dealer workshops
- Fleet maintenance centers
- Body shops, tire shops, EV service centers
- Mobile mechanics

## Core Workflow
```
CUSTOMER → VEHICLE → APPOINTMENT → CHECK-IN → INSPECTION → DIAGNOSIS →
ESTIMATE → CUSTOMER APPROVAL → REPAIR ORDER → WORKSHOP EXECUTION →
PARTS → QUALITY CONTROL → PAYMENT → VEHICLE DELIVERY → SERVICE HISTORY → NEXT SERVICE
```

## Key Differentiators
1. **Vehicle-centric data model** — Complete lifecycle tracking per vehicle
2. **Digital Vehicle Inspection (DVI)** — Configurable multi-point inspections with photo evidence
3. **Customer Digital Approval** — Secure time-limited approval links
4. **Workshop Control Board** — Real-time Kanban visibility of all operations
5. **Immutable Inventory Ledger** — Every stock change creates an auditable movement record
6. **Multi-tenant SaaS** — Tenant → Organization → Branch → Bay hierarchy
7. **AI-ready architecture** — Structured data for future predictive maintenance

## Business Model
- SaaS subscription (Starter / Professional / Business / Enterprise)
- Future transaction revenue: parts ordering, payment processing, insurance claims

## Long-term Platform Evolution
Workshop → Multi-Branch → Dealer → Fleet → Parts Ecosystem → Insurance → Connected Vehicle → AI Operations
